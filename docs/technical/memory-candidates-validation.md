## 中文质量数据

数据集：[chinese-search.json](../../tests/fixtures/chinese-search.json)。包含短语、专有名词、全角字母、TypeScript/Windows 混合词、否定、标点重复、单字、补充平面汉字、英文错字和无结果样本。固定数据上的预期集合精确匹配率 22/22；这些是明确测试预期，不是对任意自然语言的召回保证。

已知限制：去空白/标点可能扩大短语匹配；“喜欢咖啡”是子串，故同时匹配“不喜欢咖啡”，片段展示原文避免隐去否定。基础模糊是至少 50% bigram 重合，没有拼音、同义词、同音字或语义理解，短词错字与高频词可能漏报/误报。自动冲突提示依赖相同文本主题及模型主题提示，不能判断完整事实；用户确认仍是唯一生效边界。

## H10 可复现性能证据

执行：`$env:AIAPPNEST_RECORD_MEMORY_BENCHMARK='1'; node --test tests/integration/memory-benchmark.test.mjs`（先 `npm.cmd run build`）。普通 `npm.cmd test` 也运行同一基准，但不会重写证据文件或用硬件敏感时间阈值使测试偶发失败。性能不达标仍须记录并修复/明确接受，不能只看测试退出码。

环境：Windows 10.0.26300 x64、AMD Ryzen 9 8945H、16 逻辑 CPU、31 GiB 内存、Node 24.19.0。单应用 10,000 条 active 记忆，四种中英混合模板加唯一编号，7 个查询轮换。原始样本和硬件信息：[benchmark JSON](evidence/memory-candidates-benchmark.json)。

| 操作 | 缓存条件 | 样本数 | P95 ms |
|---|---|---:|---:|
| 搜索（含计数/20 条结果/片段） | 同连接预热后 | 70 | 24.00 |
| 搜索 | 新 SQLite 连接 | 21 | 30.08 |
| 注入（含预算、版本再检查、审计事务） | 同连接预热后 | 70 | 168.97 |
| 注入 | 新 SQLite 连接 | 21 | 154.32 |

首轮注入 P95 362.30ms，超过初始目标；定位为逐行重复规范化与 n-gram 编码，改用派生索引中预计算 grams 评分后降至上述值。测量不含构造运行的时间，包含注入审计提交。重开连接**没有清空 OS 文件缓存**，不能称为物理盘真冷启动；这部分仍待补。合成模板不能代表全部真实文本长度、热词分布或磁盘配置。
