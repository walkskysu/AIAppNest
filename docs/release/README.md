# Windows 内部候选包（Refs #20）

**未正式发布，最终验收 PENDING。** 本包用于受控验收，未签名，不代表 L01–L10 或前置真实模型/人工验收通过。不要用于唯一一份重要数据。

## 安装与使用

1. 从受控 CI 的 `windows-internal-candidate` artifact 下载 `*-internal-setup.exe` 和 `SHA256SUMS.txt`。用 PowerShell `Get-FileHash -Algorithm SHA256 <文件>` 对照校验和。哈希仅检查完整性，不能替代签名与下载来源验证。
2. 关闭平台并等待活动任务停止。双击安装器，当前账户安装到 `%LOCALAPPDATA%\Programs\AIAppNest\versions\<候选ID>`，不请求管理员权限。安装器不关闭其他程序、不自动启动应用；开始菜单生成启动与 Rollback 快捷方式。已有同 ID 目录拒绝覆盖。
3. 启动 `AIAppNest Internal Candidate`。首次升级启动可能需要复制数据，请等待服务就绪。默认数据根 `%LOCALAPPDATA%\LocalAIHub`；恢复后使用所选的新数据根。Electron 的用户配置位于 `%APPDATA%\aiappnest-desktop`（显式测试 profile 除外）。安装位置不存个人数据。
4. 在模型设置中配置云模型 API 或本地 OpenAI 兼容服务并测试连接；创建应用、发布配置、新建会话、执行任务、查看产物、保存记忆并在新会话复用。无需安装 Node/npm/Pi。模型服务、模型权重及其算力不随包附带。
5. 使用云模型时，选入上下文的对话、文件、Skill 和记忆发送给所选模型服务商。本地保存不代表离线计算。无效凭据、离线、模型不兼容应展示错误；不会自动重发任务。

仅支持 Windows 11 x64。系统自带 .NET Framework 4.x 用于 DPAPI、进程树和安装辅助程序；Node 24.19.0 内置 SQLite 在独立 Node 进程执行，不使用 Electron ABI。Pi 的可选原生包按锁文件的 Windows x64 预编译资源交付，必须通过包内验证。

Skill 的 Python、Git Bash、外部程序与系统授权不随包提供。纯提示 Skill 可直接使用；依赖脚本的 Skill 应先核对依赖、可信来源与权限。可信自动化具有当前账户权限，首版不提供恶意代码 OS 沙箱。

## 手动升级与回退

- 安装新候选只添加版本目录，保留旧二进制。关闭旧平台后启动新版本；独占数据锁会拒绝第二个 Service Host。正常关窗会停止任务与进程树；故障退出后的任务由已有恢复流程标为中断，不能自动重放。
- 新版本先在独立夹具目录通过 prompt、流式、停止、恢复、Skill、权限拒绝的构建门槛。数据升级先检查同卷可用空间（复制量的 2 倍另加 256 MiB），用 SQLite backup API 生成一致性 DB 副本，并逐文件复制校验。仅副本运行数据库迁移和完整性校验。
- 数据根旁的 `<根>.snapshot-<UUID>` 保留升级前原根；原始 Pi JSONL 不改写。`.upgrade.json` 是持久事务记录；`.stage-*` 是准备目录。迁移失败不提交；提交中断时下次启动继续完成目录交换，不混合 schema。文件占用会失败并保留目录，释放占用后重试。此机制是同账户本机回退，快照含 DPAPI 密文，不能当成可分享导出包。
- 不兼容 Pi/适配器/扩展/session 组合会在迁移前拒绝。此版本不实现跨协议转换；不得手改 JSONL 绕过检查。未标记的导入数据仅允许与当前 schema 完全一致，否则要求旧版本导出后使用受支持的迁移流程。
- 回退：先关闭平台，从开始菜单运行 `AIAppNest Internal Candidate - Rollback`。确认窗口列出根、快照时间和旧版本，说明升级后新增对话、产物、记忆、设置、凭据将退出当前视图。确认后恢复快照，启动匹配旧二进制；升级后原根仍保留在另一个 snapshot 目录。不可仅手动启动旧 exe 打开新 schema。
- 回退不是合并数据。不自动重放任务，不恢复外部工具在授权目录造成的外部副作用。旧版本、快照与事务记录均需保留，至少完成真实回退演练后才人工清理。
- 回退后的后续启动请使用确认窗口中旧版本目录对应的 `AIAppNest.exe`（位于其 `resources/app` 的上两级）。开始菜单普通快捷方式仍指向最后安装版本，再次点击相当于再次尝试升级；本版不提供后台更新或自动重写快捷方式。
- 若服务启动失败，先保留所有目录，检查空间、占用及旧版本是否仍在；可使用旧版本配原快照。不要直接删掉事务记录或复制部分 DB。未完成的 `.incomplete-*` 安装目录不会被快捷方式引用，可在确认无安装器运行后删除。

## 备份、凭据与卸载

日常跨账户备份使用界面“一致性备份”，它排除凭据及外部目录授权；恢复到新目录后重新绑定模型 API Key，并重新授予外部目录权限。必须补齐 #19 新 Windows 账户、真实原始会话/产物恢复验收。

Windows 设置中的卸载项删除候选二进制与快捷方式，默认保留数据根、Electron profile、同卷快照和备份。小型卸载器本身保留在安装父目录，可在退出后手动删除。重新安装同兼容版本会重新连接原数据；若恢复后使用了自定义根，保留 profile 的根指针。卸载后旧二进制不再可用于回退，应先保留候选安装器/ZIP。删除个人数据必须由用户另行明确执行。

## 已知限制与安全提示

内部候选没有 Authenticode 签名；SmartScreen、Defender、下载标记和组织策略的实际提示仍待干净机记录。即使未来签名也不能保证不提示。签名证书、硬件密钥/云签名服务、组织主体尚未提供。正式签名不能勾选通过。

锁定依赖当前存在 npm audit 高危告警，见仓库验收记录；正式发行前必须评估并修复或取得有依据的安全处置，不能通过把测试夹具成功写成真实验收而放行。
